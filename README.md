# Hash-Check

Windows 资源管理器哈希校验扩展：右键生成校验文件、右键校验、双击打开验证窗增删改查。当前形态（1.8.2）= 纯明文无签名无加密（校验文件 v2=哈希行+日期字段+时间戳）+ 验证端多线程并行（开始/校验选中走 ConcRT parallel_for_each，保存更改重算走 N 线程原子认领；进度字节级聚合定时刷新）+ 底部两键（开始|更多）+ 更多菜单（添加文件/添加文件夹/保存更改）+ 开窗自动比对+实时监测（ReadDirectoryChangesW，变化聚合弹窗）+ 右键状态菜单（添加/删除/更新/校验选中）+ 收录限校验文件所在目录树内+ 验证窗右键维护通道（添加/删除/更新）+ 零打扰安装；chk 定位器已随功能链铲除（1.6.9，无签名形态下防不了蓄意篡改）。基于开源 HashCheck（Kai Liu）深度定制。

## 使用方法

- **安装**：运行安装包，全程零弹窗零询问，装完只剩「完成」按钮；被占用的旧版 DLL 由 rename-dance 落盘、下次系统重启自然生效
- **生成**：资源管理器选中文件/文件夹 → 右键 →「哈希」→ 保存校验文件 → 得到明文 `.sha256`：哈希行 + 时间戳（VS Code 可直读可手改；1.6.9 起 chk 行不再生成）
- **验证**：右键校验文件 →「校验」（或双击打开）→ 验证窗逐条对账：相符绿 / 不符红 / 缺失黄 / 新增蓝 / 未验 / 存疑（1.7.0 更名自「已变化」，1.7.2 起状态列紫底；1.6.9 起无损坏态）
- **更多**：验证窗底部「更多」按钮（1.7.6 四项）——添加文件（多选；限校验文件所在目录树内，越界提示不收录）/ 添加文件夹（递归；同范围限制）/ 检测变化（mtime+大小轻检）/ 保存更改（三键询问：全部重算/仅保存修改/取消；重算期间开始键变「暂停」+进度条按字节走动）
- **右键维护**：验证窗右键行——「添加」（仅新增行：重算入册→相符）/「删除」（仅册内行：先弹确认窗列出目标；确认后盘上仍在的条目转新增态、已缺失的移除，盘上文件不碰）/「更新」（仅不符行：以现在为准，基线同步→相符）/「校验选中」（选中集含册内行时显示：只校验选中条目，暂停态可用）；多选混合时按选中集并集显示、各操作只作用于自己适用的行；右键操作全内存态，落盘走更多菜单「保存维护」，关窗不保存=全部作废（反悔通道）
- **快捷键**：Ctrl+C 复制选中行（文件名+哈希）、Ctrl+A 全选（1.7.6 起右键菜单不再提供复制/全选）；点列头排序
- **选项**：右键 →「哈希」→ 选项——算法选择等设置
- **兼容**：可打开 1.4.9+ 带 chk 的旧明文校验文件；旧加密容器格式已随无加密线退役
